# Jae-hwan Kim — Portfolio

Personal portfolio site. Plain HTML/CSS, no build step, served by GitHub Pages.

- `index.html` — all content
- `styles.css` — color tokens at the top (light + dark)
- `assets/media/` — each animation is a `.jpg` still plus a `.webp` that plays on hover/tap

Layout adapted from [Jon Barron's website](https://github.com/jonbarron/jonbarron.github.io).
